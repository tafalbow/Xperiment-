# Kamus Data Terstandarisasi (24 Atribut Metadata)

Setiap dataset dan indikator dalam repositori **"Pergerakan Ekonomi Indonesia"** memiliki 24 atribut metadata terstandarisasi untuk menjamin kepatuhan tata kelola data nasional:

| No | Atribut Metadata | Deskripsi Standar | Contoh Nilai |
|---|---|---|---|
| 1 | **Dataset ID** | Identifikator unik dataset tingkat kelompok | `DS-APBN-NAT` |
| 2 | **Indicator ID** | Identifikator unik indikator nasional | `IND-APBN-REV-TOT` |
| 3 | **Unique Variable Code** | Kode variabel teknis terstandarisasi | `VAR_APBN_PENDAPATAN_TOTAL` |
| 4 | **Nama Indikator** | Nama variabel resmi dalam Bahasa Indonesia | `Pendapatan Negara dan Hibah` |
| 5 | **Definisi Indikator** | Definisi operasional dan ruang lingkup variabel | `Total seluruh penerimaan pemerintah pusat yang berasal dari perpajakan, PNBP, dan hibah.` |
| 6 | **Sektor** | Sektor makroekonomi / pembangunan | `Fiskal & Keuangan Negara` |
| 7 | **Kategori** | Kategori statistik | `Anggaran Pendapatan dan Belanja Negara` |
| 8 | **Subkategori** | Rincian subkategori indikator | `Pendapatan Negara` |
| 9 | **Sumber Data** | Jenis sumber data primer/sekunder | `LKPP Audited BPK RI & UU APBN` |
| 10 | **Lembaga Penerbit** | Lembaga pemerintah resmi yang menerbitkan | `Kementerian Keuangan Republik Indonesia` |
| 11 | **Nama Publikasi** | Judul resmi dokumen publikasi | `Laporan Keuangan Pemerintah Pusat (LKPP) Audited` |
| 12 | **Periode Data** | Rentang historis data yang tersedia di repositori | `1993 - 2024` |
| 13 | **Frekuensi** | Frekuensi pembaruan / rilis publikasi | `Tahunan` |
| 14 | **Geographic Scope** | Cakupan wilayah administratif | `Indonesia / National` |
| 15 | **Satuan** | Satuan baku pengukuran | `Triliun Rupiah` |
| 16 | **Metodologi** | Standar akuntansi / statistik yang digunakan | `Standar Akuntansi Pemerintahan (SAP) berbasis akrual.` |
| 17 | **Tanggal Publikasi** | Tanggal resmi rilis dokumen publikasi | `2024-06-15` |
| 18 | **Tanggal Diperoleh** | Tanggal data di-retrieve oleh sistem | `2024-07-01` |
| 19 | **Tanggal Diperbarui** | Timestamp pembaruan data terakhir di repositori | `2024-12-21` |
| 20 | **Status Data** | Kebijakan status keandalan data | `Observed (Final Audited LKPP) / Provisional (APBN KiTa)` |
| 21 | **Source URL** | Tautan resmi dokumen publikasi | `https://www.kemenkeu.go.id/lkpp` |
| 22 | **Referensi Halaman/Tabel** | Sitasi nomor halaman dan tabel dokumen resmi | `Lampiran 1.A, Halaman 45-52` |
| 23 | **Catatan Metodologi** | Catatan khusus transisi metode / tahun dasar | `Harmonisasi pos belanja pra-2005 via Classification Crosswalk UU 17/2003.` |
| 24 | **Catatan Revisi** | Catatan revisi bila angka provisional diubah | `Angka 2023 disesuaikan dari APBN KiTa ke LKPP Audited BPK.` |
